# .wstaticmodel Format Changelist
#
# Format: single integer version field; any change is breaking.
# Loader rejects files whose version != STATICMODEL_VERSION.
# Asset generator uses ReadWStaticModelHeaderAnyVersion to detect and regenerate stale files.
# Magic: "WSTCMDL" (7 chars, char[8])
# Header: WStaticModelHeader in model_format.h

================================================================================
VERSION 6  (current)
================================================================================
- Added per-primitive bounds to `PrimitiveProperty`: `boundingBoxMin`/`boundingBoxMax`
  (Vec3) and `boundingSphere` (Vec4, xyz center + w radius). `primitiveProperties` is
  raw-dumped (WriteVector/ReadDynamicVector at sizeof(T)), so the struct growth shifts the
  on-disk layout, hence breaking. Repopulated at load from the geometry `Primitive` array;
  used for per-primitive framing/zoom.

================================================================================
VERSION 5
================================================================================
- Undocumented; see git history.

================================================================================
VERSION 4
================================================================================
- Undocumented; see git history.

================================================================================
VERSION 3
================================================================================
- Merged major/minor version fields into a single `version` field.
- Added `lightingShader` field to `Material` (default: "default_pbr"). Written
  and read alongside `fragmentShader` in WriteMaterial/ReadMaterial.
- Added ReadWStaticModelHeaderAnyVersion for asset generator use (no version rejection).

================================================================================
VERSION 2.4
================================================================================
- Added `fragmentShader` field to `Material` to associate a fragment shader with
  each material entry. Immutable materials always use default_lit; no exceptions.

================================================================================
VERSION 2.3
================================================================================
- Added `shadingBucketIndex` field to `MaterialProperties` (model_interop.h) to
  support shading dispatch bucketing.

================================================================================
VERSION 2.2 and earlier
================================================================================
- Pre-changelist. See git history for details.
